## 1. Functional Specification (기능 명세서)

### 1.1 배경 및 목적
1. **단일 거대 지침 비대화 방지**: 스타터 킷 기반으로 프로젝트가 확장될 때 `AGENTS.md`가 40KB~70KB로 비대화되어 LLM 시스템 프롬프트가 잘리는 문제를 원천 차단하기 위해 템플릿 단계부터 모듈화 구조를 채택합니다.
2. **5단계 멀티 에이전트 표준화**: Next.js App Router 엔터프라이즈 환경에서 기획(Discovery 4인) ➔ 계획(Planner) ➔ 테스트 설계(Test Architect TDD) ➔ 구현(Coder) ➔ 검증(QA Tester & Reviewer)으로 이어지는 표준 파이프라인 가이드를 제공합니다.

### 1.2 기능 변경 상세
1. **모듈화 룰 템플릿 체계 (`agents/rules/`)**:
   - `01_STITCH_AND_DESIGN_SPECS.md`: Stitch 3기둥 컨텍스트, 무스피너 캡처, 공통 UI 재사용 원칙.
   - `02_PLANNING_AND_PR_HISTORY.md`: PR 단위 구현 계획서 누적 및 계획 수립 프로토콜.
   - `03_HARNESS_AND_VERIFICATION.md`: 3단계 전주기 5-Gate 하네스 및 진단서 초압축.
   - `04_ARCHITECTURE_PATTERNS.md`: Next.js App Router, MVVM Single ViewData, DTO 매퍼.
2. **멀티 에이전트 5단계 협업 파이프라인 (`agents/MULTI_AGENT_PIPELINE_GUIDE.md`)**:
   - Discovery 4인, Planner, Test Architect (Shift-Left TDD), Coder, QA Tester & 5-Gate Reviewer 협업 체계.
   - 듀얼 트랙(경량 패스트트랙 vs 5단계 풀팀) 및 응답 시작 시 상단 1회 배지 표기 표준화.
3. **용량 예산 자동 감사 (`harness/scripts/check-agents-size.ts`)**:
   - `AGENTS.md` 28KB 안전 목표, 40KB 하드 리밋(초과 시 빌드 차단).
4. **스캐폴딩 및 문서 동기화**:
   - `AI_SCAFFOLD_DIRECTIVE.md`, `setup/PACKAGE_JSON.md`, `harness/HARNESS_GUIDE.md`, `README.md` 동기화.
